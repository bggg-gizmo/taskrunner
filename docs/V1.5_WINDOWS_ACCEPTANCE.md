# Task Runner v1.5.1 Windows acceptance checklist

Run `BUILD_WINDOWS.cmd` on Windows 10/11 using the regular shared Python x64 installation. Do not remove or replace existing Python environments.

- [ ] All source tests pass; dependency checker resolves `psutil>=5.9,<8` and prior dependencies.
- [ ] `dist\TaskRunner\TaskRunner.exe` self-test succeeds (including OCR inference, UI and browser).
- [ ] The existing Dashboard, New Task wizard, Execution Logs, Output Gallery and Settings still render identically to v1.4.
- [ ] New Resource Monitor appears as a sidebar entry; page displays system RAM and the selected PID's memory without requiring elevation.
- [ ] Test a nonexistent or inaccessible PID; it gives a readable error and does not crash the GUI.
- [ ] Check NVIDIA GPU VRAM on an NVIDIA system: GPU totals appear; compute allocation is only shown when reported. On AMD/Intel systems or without drivers, display says unavailable, not zero.
- [ ] Run snapshot, start guard, warning threshold and stop guard in a test workflow; verify event logs and workflow variables.
- [ ] Run cancellation policy and confirm the workflow stops without killing the target app.
- [ ] Explicitly choose owned-process termination on a disposable test program and confirm it stops only the launched process tree.
- [ ] Attempt to terminate an unrelated PID and verify it is rejected before any termination.
- [ ] Leave a warning-only guard running after the inspected PID exits and a new process starts: confirm PID reuse cannot cause monitoring of the unrelated process.
- [ ] Stop a guard during a slow GPU query and verify no new cancellation or process termination is initiated after stop.
- [ ] Simulate an installation failure during Start Menu/registry registration and verify the previous installed EXE is restored.
- [ ] Verify emergency stop, recording, teach-by-correction, OCR, clipboard/image capture, scheduler, installer/uninstaller and browser workflow still work.
- [ ] Verify archived v1.2.1, v1.3.0, v1.4.0 source snapshots, README links, icons and seven original audio files.

**Not executed on this Linux build host:** native Windows acceptance, GUI screenshot capture, PyInstaller EXE and GPU driver telemetry.

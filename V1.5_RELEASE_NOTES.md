# Task Runner v1.5.0 — Resource Monitor and OOM Safeguards

## What's new

Task Runner now offers **opt-in process RAM and NVIDIA compute VRAM monitoring**. This is intended for workloads such as local AI tools, image generation, long-running automation, and programs that may consume memory while Task Runner waits for output.

- **Resource Monitor** sidebar page provides a read-only, auto-refreshing overview of total/available system RAM and, for a user-selected PID, total RSS and process-tree size.
- **NVIDIA VRAM** button queries locally installed `nvidia-smi` for total VRAM consumption and separately for the inspected PID's compute allocations. No additional driver is installed. Missing/unreported data displays as unavailable, never zero. AMD/Intel GPU telemetry is not implemented.
- **Record RAM / VRAM snapshot** workflow action saves `memory_process_ram_mb`, `memory_system_available_mb`, `memory_system_used_percent`, and `memory_gpu_vram_mb` variables.
- **Start RAM / VRAM guard** action watches a selected PID (or last program launched in the current workflow), every 0.2–60 seconds. Configure process tree RAM maximum, minimum available system RAM, and NVIDIA compute VRAM maximum independently. Zero disables a limit.
- **Warning-only by default.** Active threshold changes are logged once per crossing/recovery; numerical fluctuations do not flood logs.
- **Explicit policy responses:** `warn`, `cancel_workflow` (does not terminate external programs), and `terminate_owned` (only an explicitly configured process started by *this* Task Runner workflow, with PID creation-time validation). No arbitrary PID termination, no automatic file deletion.
- **Stop RAM / VRAM guard** action writes `memory_peak_process_mb` and `memory_sample_count` variables; watcher stops on workflow completion or cancellation as well.
- **Shared Python dependency:** psutil (installed by the same existing dependency manager), included in PyInstaller module collection.
- **Tests:** new resource-policy, process identity, threshold, GPU parser and workflow integration checks. Older workflows remain valid without migration.

## Boundaries and safety

Monitoring is opt-in, except for the read-only Resource Monitor view while it is open. The program monitors RAM for a selected process plus its child processes; the summed RSS is an estimate and may double-count shared pages. VRAM support is limited to NVIDIA drivers offering the local `nvidia-smi` compute query; not all graphical applications report their allocations. The feature cannot fix another program's memory leak, guarantee allocation recovery, or prevent out-of-memory situations that develop faster than the polling interval.

Use a warning threshold first, then raise or lower it based on measured consumption. Termination is never enabled by default. Task Runner's original recorder, all automation actions, visual debugger, Output Gallery, settings, vault, scheduler, seven sounds, installer/uninstaller, Windows source build and all archived releases are retained.

**Build validation:** 131 Linux source tests passed, with 3 skipped; pre-publication audit passed. Native Windows EXE and GPU-driver acceptance still require Windows testing.

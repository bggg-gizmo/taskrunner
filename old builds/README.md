# Previous Task Runner Builds

Archived, complete source trees for previously published Task Runner versions. These are **source snapshots**, not precompiled Windows executables. Each directory contains that release's original application, assets, build scripts, and regression tests.

| Version | Source snapshot | Notes |
| --- | --- | --- |
| **v1.2.1** | [Browse complete source](v1.2.1/) | Previous Windows automation release before native task recording and live capture |
| **v1.3.0** | [Browse complete source](v1.3.0/) | Desktop recording, visual waits, output capture and installer/uninstaller |
| **v1.4.0** | [Browse complete source](v1.4.0/) | Playback debugger, offline OCR, precision and Python 3.13 OCR build fix |

Current development and release source is in the repository root. See the [main changelog](../CHANGELOG.md). Archived versions are preserved as-is for reproducibility and comparison; fixes belong in the active source, not in these snapshots.

**Security:** Archived versions are not the recommended production version. Review [SECURITY.md](../SECURITY.md) before executing imported workflows.

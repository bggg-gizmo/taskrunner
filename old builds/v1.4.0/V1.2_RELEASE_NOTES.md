# Task Runner v1.2.1 — Release notes

**Developed by the Background Gremlin Group**  
**Creating Unique Tools for Unique Individuals**

This release extends the complete existing Windows task editor and execution engine. The vaporwave theme, five toggleable interface sounds, custom icon, all earlier automation steps, optional verification, scheduling, SQLite data store, import/export, execution logs, background runner, and shared dependency model remain intact.

## Added actions

| Action | Where | Actual operation and saved outputs |
| --- | --- | --- |
| Expand browser page dropdowns | Browser | Open `<details>` disclosures and eligible ARIA controls; enumerate native select options without changing them. JSON stored in named variable; total in `${dropdown_count}`. |
| Select browser dropdown choice | Browser | Select an HTML `<select>` option by label, value or zero-based index. |
| Capture entire scrolling web text | Browser | Scroll a page or specific overflow container to discover more text; deduplicate captured lines; save the result in a variable and optionally in clipboard; number of scroll increments in `${scroll_count}`. |
| Inspect Windows app dropdowns | Windows | Use UI Automation to expand supported ComboBox/Button/TreeItem controls sequentially, collect options where exposed, and collapse those originally closed. JSON report in named variable. |
| Capture scrolling Windows app text | Windows | Prefer full accessible TextPattern document; otherwise use Ctrl+A/C while scrolling in bounded increments. Result in named variable and optional clipboard. |
| Wait for Windows window | Windows | Block until title match appears or disappears, with a timeout and cancellation. |
| Wait for file or folder | Files | Block until path exists or is absent, with timeout and cancellation. |
| Wait for browser element state | Browser | Wait for visible, hidden, attached or detached DOM state. |

Every action also has a new **Wait BEFORE action (seconds)** timing setting; retries, retry pause, after-action pause, and verification remain independently configurable. The **Wait** action and existing one-second scheduling interval remain intact.

## Dependency fix reported from Windows

On a shared Python 3.13 Windows installation, pip previously stopped when it could not access a cached `pyautogui` wheel (`Permission denied` inside `%LOCALAPPDATA%\pip\cache\wheels`). The shared dependency checker now detects permission/locking failures, retries installation with `--no-cache-dir`, and keeps the installation in the same shared `--user` Python site-packages. It does not request elevation, delete existing caches, introduce a virtual environment, or remove other packages. If an installation still fails, the real error is surfaced.

## Windows EXE metadata and UI

The application identifies its developer in the navigation panel and Settings > About section, in Python application organization metadata, and in PyInstaller's PE version resource. Native wizard/editor content now scrolls if its height exceeds the display, with Save/Cancel buttons retained outside the scroller.

## Known technical behavior

- Browser and Windows-native dropdowns cannot generally all stay visibly open simultaneously; controls are expanded sequentially, and choice lists are collected in variables when possible. Custom-painted controls that do not expose UI Automation properties may be inaccessible.
- Dynamically loaded page text is captured only when the site renders it during bounded scrolling. The browser collector deduplicates identical text lines (which can suppress legitimately repeated identical lines). It stops with an error when its text safety cap is reached.
- Native text extraction depends on accessibility or the program's support for Ctrl+A/C. The fallback can change focus and scroll position. The original **text** clipboard is restored after extraction, unless the action is configured to copy results. Native clipboard formats other than text are not preserved by the fallback.
- Sub-minute schedules are checked every second with the GUI open. The installed Task Scheduler background heartbeat is one minute, so sub-minute schedules with the GUI closed may be delayed.
- Visual automation requires an interactive unlocked Windows session. The executor and interface are not yet certified on actual Windows hardware in this Linux environment.
